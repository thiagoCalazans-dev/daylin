# Daylin

Jogo de microlearning para estudar qualquer tema com sessões curtas e constantes. O usuário envia um material, recebe perguntas baseadas nele e avança por um tabuleiro que sobe um vulcão lúdico.

O projeto está **em planejamento**. A aplicação ainda não foi implementada.
