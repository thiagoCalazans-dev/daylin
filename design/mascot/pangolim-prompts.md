# Pangolim — prompts dos sprites

Imagens geradas com a ferramenta integrada `image_gen`, usando os sprites da tartaruga apenas como referência de estilo e pose. O pangolim neutro é a referência visual das demais poses.

## Neutro

Referência: `tartaruga-neutra.png`.

> Use case: style-transfer. Asset type: transparent pixel-art mascot sprite. Create one original pangolin based on the attached turtle ONLY for pixel style and outfit. Recognizable pangolin: elongated narrow muzzle, warm honey face and arms, overlapping dark emerald scales on back, long thick scaled tail curling beside body; no turtle shell or plastron. Large square black glasses, bright orange neckerchief, navy sneakers. Neutral friendly standing full-body pose, one raised hand. Crisp 16-bit pixel art with dark outlines. Transparent background, no text, no watermark, one character.

## Base das outras poses

Referência 1: `pangolim-neutro.png`. Referência 2: sprite da tartaruga com a pose correspondente.

> Use case: style-transfer. Asset type: transparent 16-bit pixel art game mascot sprite. Reference 1 is the CANONICAL pangolin character: preserve exact identity, warm honey beige face and belly, short narrow pangolin snout with brown nose, black square glasses with orange corner pixels, olive and dark emerald overlapping scales on top of head/back, long thick curled scaled tail, orange neckerchief, navy sneakers, dark pixel outlines, same pixel density and proportions. Reference 2 is an older turtle sprite used ONLY for the emotion and pose. Replace that turtle entirely with canonical pangolin. Absolutely NO turtle shell, NO plastron, NO green turtle skin. One full-body character, transparent alpha background, no text, no watermark, no scenery.

### Acerto

> A joyful correct-answer celebration: closed smiling eyes, wide smile, one fist raised, one leg kicking up, a few small golden pixel sparkles. Match Reference 2's upbeat pose.

### Erro

> A kind learning-from-error reaction: slight thoughtful frown and raised eyebrow, one hand gently scratching side of head, two tiny blue question/hesitation drops. Never sad or ashamed. Match Reference 2's pose.

### Alerta

> A gentle alert / helpful tip reaction: eyes wide, small open mouth, one finger raised, a single yellow pixel exclamation mark floating beside the head. Match Reference 2's pose.

### Combo

> A confident streak celebration: joyful expression, one fist high, one leg lifted, several golden sparkles and a small amber pixel swoosh around the body. Match Reference 2's energetic pose; keep the tail clearly visible.

### Ofensiva

> A nonviolent learning-challenge hero pose: feet planted apart, focused smile, one arm holding a pencil wand with a cyan glowing plus/question symbol, other hand bent at waist. Match Reference 2's heroic pose; no weapon or violence.
